MC-WEB / SELF-HOSTED

      
Play Minecraft
from this computer.

      
MC-Web builds Minecraft for your browser and runs it from the local server on this computer. Sign in, build the game if needed, install it in this browser, and play. Your account credentials and game files stay on this computer.


      

        
1. Verify your Minecraft account

        
Use the Microsoft account that owns Minecraft: Java Edition. MC-Web supports the official Minecraft Launcher and PrismLauncher.

        
    
          
  1. Sign in with Microsoft here, or open your launcher and sign in.
    2. 
          
  2. For launcher sign-in, return here so the local server can check the account.
    3. 
          
  3. Continue when the account status says verified.
    4. 
        

        

          
          OR USE A LAUNCHER .JSON FILE
        

        

          ACCOUNT NOT FOUND?
          
If the account status does not change, choose the launcher's account file below.

          

            

              
Windows

              
Press Win+R, enter %APPDATA%\.minecraft, and press Enter. Choose this file:

              %APPDATA%\.minecraft\launcher_accounts.json
            

            

              
macOS

              
In Finder, choose Go → Go to Folder… and enter ~/Library/Application Support/minecraft. Choose this file:

              ~/Library/Application Support/minecraft/launcher_accounts.json
              
For PrismLauncher, choose:

              ~/Library/Application Support/PrismLauncher/accounts.json
            

            

              
Linux

              
Open ~/.minecraft in your file manager. Choose this file:

              ~/.minecraft/launcher_accounts.json
            

          

          

            
            
            
Choose launcher_accounts.json from the official Launcher or accounts.json from PrismLauncher.

          

          
This page sends the selected file only to this loopback Node process for validation. The process does not write the file, keep it, or send it to a public host. The account token never enters browser storage.

          

            SUPPORTED FILE FORMATS
            
The official Launcher file needs an accounts map, activeAccountLocalId, an unexpired accessToken, and minecraftProfile. The PrismLauncher file needs a numeric formatVersion, one active MSA account, an unexpired ygg.token and ygg.exp, and a profile.

            
If the official Launcher file has no reusable token, sign in again or choose the PrismLauncher file. For a custom path, set MCWEB_LAUNCHER_ACCOUNTS before you start the local server.

2. Build, install, and play

        
Follow the first available action below. If this browser already has the current build, go straight to Play Minecraft.

        
    
          
  1. If no browser build is ready, click Build game for browser. The first build takes longer because it downloads the build tools.
    2. 
          
  2. When the build finishes, click Install in this browser.
    3. 
          
  3. When Account says verified and Browser says installed, click Play Minecraft.
    4. 
        

        
Build: checking for a browser build.

        

        

        
        

          BUILD FROM THE TERMINAL
          
If the build button is unavailable, run the command for your operating system from the public/mcweb checkout.

          

            
macOS

            
node tools/build.mjs --mc-dir "$HOME/Library/Application Support/minecraft" --out dist/build

            
Linux

            
node tools/build.mjs --mc-dir "$HOME/.minecraft" --out dist/build

            
Windows PowerShell

            
node tools/build.mjs --mc-dir "$env:APPDATA\.minecraft" --out dist/build

          

          
When the command finishes, return to this page. The local server finds build/web-graal/graal/minecraft-client.js.wasm on this computer. You do not need to upload it.
