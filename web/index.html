This page is served by the self-hosted Node process that reads a supported local Minecraft launcher session, builds the player-supplied image, and serves it only on this machine. Credentials and generated game files stay local.


      

        
1. Launcher session

        
Use either the official Minecraft Launcher or PrismLauncher. The self-hosted Node process reads the selected local account file, validates the active Microsoft account, token freshness, Minecraft ownership, and live profile with Minecraft Services, and never sends the token to this page or a public host.

        

          

            
Windows

            
Press Win+R, enter %APPDATA%\.minecraft, and press Enter. The expected file is:

            %APPDATA%\.minecraft\launcher_accounts.json
          

          

            
macOS

            
In Finder, choose Go → Go to Folder… and enter ~/Library/Application Support/minecraft. The expected file is:

            ~/Library/Application Support/minecraft/launcher_accounts.json
            
PrismLauncher alternative:

            ~/Library/Application Support/PrismLauncher/accounts.json
          

          

            
Linux

            
Open ~/.minecraft in your file manager (or use Ctrl+L and enter that path). The expected file is:

            ~/.minecraft/launcher_accounts.json
          

        

        
The already-running Node process can read a detected file directly, or you can choose one below. A selected file is sent only to this loopback Node process for validation; it is not sent to a public host, written to disk, or retained by the page. Supported formats are the official Launcher's top-level accounts object map with activeAccountLocalId, a Microsoft account with an unexpired string accessToken, and minecraftProfile; or PrismLauncher's top-level numeric formatVersion with an accounts array, exactly one active MSA account, an unexpired ygg.token/ygg.exp, and profile. Some current official Launcher files omit a reusable accessToken; use the PrismLauncher file or sign in again when that happens. For a nonstandard install, the server operator can set MCWEB_LAUNCHER_ACCOUNTS to the local file path before launching this self-hosted server.

        

          
          
          
Choose launcher_accounts.json from the official Launcher or accounts.json from PrismLauncher. The raw file is used once and then discarded from the page.

2. Build and install locally

        
The self-hosted Node process can run the local build in this checkout. The build reads your own Minecraft installation, keeps proprietary inputs on this machine, and reports only a safe phase label to this page. When the build finishes, install the two hash-verified Wasm artifacts into this browser.

          BUILD FROM TERMINAL
          
From the public/mcweb checkout, use the command for your operating system if the server build action is unavailable:

          

            
macOS

            
node tools/build.mjs --mc-dir "$HOME/Library/Application Support/minecraft" --out dist/build

            
Linux

            
node tools/build.mjs --mc-dir "$HOME/.minecraft" --out dist/build

            
Windows PowerShell

            
node tools/build.mjs --mc-dir "$env:APPDATA\.minecraft" --out dist/build

          

          
After the command completes, return here. The running self-hosted Node process serves the newly generated build/web-graal/graal/minecraft-client.js.wasm; no upload is involved.

        

        
The browser verifies the two allowlisted build artifacts in private browser storage before Play; no generated runtime or audio files are part of this source copy.
